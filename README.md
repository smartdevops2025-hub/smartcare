# 🏥 SMARTCARE — Nursing Induction System

**Competency-based induction for ICU, OT & Infection Control**

## Features
- ✅ Staff nurse details entry
- ✅ Pre-evaluation & Post-evaluation
- ✅ Training completion tracking
- ✅ 3 privilege levels based on performance
- ✅ Department levels (ICU / OT / Infection Control)
- ✅ Admin, Supervisor, Nurse roles
- ✅ Reports & Tracker sheet
